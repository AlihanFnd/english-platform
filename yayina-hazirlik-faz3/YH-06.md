# YH-06 — Gerçek aralıklı tekrar

> **Bağımlılık:** YH-04 (tekrar puanı), YH-05 (cümleler de aynı algoritmayı kullanır).

---

## Hedef

> **Her kelime ve cümle bir sonraki tekrar zamanını taşıyacak; çalışma seansı
> önce vakti gelenleri getirecek; panel "bugün N tekrar seni bekliyor" diyecek;
> ve bu zamanlar yalnızca sunucuda hesaplanacak.**

---

## Mevcut durum

`GET /books/words/calisma` sırası (`BooksController.cs:548-552`):

```
1) hiç çalışılmamış  2) çalışılıyor (DogruSeri < 3)  3) öğrenilmiş
aynı bant içinde: SonCalismaAt eskiden yeniye, sonra RASTGELE
```

Eksik olan **zaman**: dün öğrenilmiş bir kelime ile 3 ay önce öğrenilmiş bir
kelime aynı bantta. Unutma eğrisi hesaba katılmıyor; "bugün ne çalışmalıyım?"
sorusunun cevabı yok.

---

## Algoritma — Leitner kutuları (açıklanabilir olduğu için)

| Kutu | Doğru bilinince sonraki tekrar |
|---|---|
| 0 | hiç çalışılmadı |
| 1 | 1 gün |
| 2 | 2 gün |
| 3 | 4 gün |
| 4 | 7 gün · **"öğrenildi" eşiği** |
| 5 | 15 gün |
| 6 | 30 gün |
| 7 | 60 gün (tavan) |

- **Bildi:** `Kutu = min(Kutu + 1, 7)` · `SonrakiTekrarAt = şimdi + aralık(Kutu)`
- **Bilemedi:** `Kutu = 1` · `SonrakiTekrarAt = şimdi + 10 dk` (aynı gün yeniden görür)
- `DogruSayisi / YanlisSayisi / SonCalismaAt` korunur (istatistik, dışa aktarma).
- `DogruSeri` geriye uyumluluk için kalır; "öğrenildi" kararı artık `Kutu >= 4`.

> **Neden SM-2/FSRS değil:** kullanıcıya "bu kelime 4. kutuda, 7 gün sonra
> gelecek" diye **anlatılabilen** bir model. Kolaylık katsayısı olan modeller
> daha verimli ama açıklanamaz. Geçiş ileride tek dosyada yapılabilsin diye
> aralık tablosu `Contracts/KelimeCalismasi.cs`'te tek kaynak.

---

## Şema

`WordListItems` ve `CumleKayitlari`'na: `Kutu int NOT NULL DEFAULT 0`,
`SonrakiTekrarAt timestamp NULL` + `(UserId, SonrakiTekrarAt)` indeksi.

### Mevcut satırların doldurulması (migration içinde SQL)

```sql
UPDATE "WordListItems" SET
  "Kutu" = CASE WHEN "SonCalismaAt" IS NULL THEN 0 ELSE LEAST(GREATEST("DogruSeri", 1), 4) END,
  "SonrakiTekrarAt" = CASE WHEN "SonCalismaAt" IS NULL THEN NULL ELSE now() END;  -- hepsi bugün vadeli
```

> Hepsini "bugün vadeli" yapmak bilinçli: eski veride tekrar zamanı yok;
> tahmin etmek yerine bir kez sıraya sokmak dürüst.
> 🔴 Migration öncesi **yedek** (faz 2 00 dosyası).

## API değişiklikleri

| Uç | Değişiklik |
|---|---|
| `GET /books/words/calisma?adet=&mod=tekrar\|serbest` | `tekrar` (varsayılan): `SonrakiTekrarAt <= now` eskiden yeniye → sonra hiç çalışılmamış (günde en çok 10 yeni). `serbest`: eski davranış |
| `POST /books/words/calisma-sonucu` | kutu/zaman hesabı; istek hâlâ yalnızca `kelimeId + bildim` |
| `GET /books/words/ozet` | `+ BugunTekrar`, `+ YarinTekrar`, `+ KutuDagilimi[8]` |
| `GET /api/cumleler/*` | aynıları |

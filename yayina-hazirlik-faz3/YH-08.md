> **Karar bağımlılığı:** gizlilik metni (insan #6), OCR butonları (insan #7).

## Hedef

> **Mobil kullanıcı hesabını uygulamanın içinden yönetebilecek (şifre değiştirme,
> verisini indirme, hesabını silme), gizlilik politikasına ve koşullara
> ulaşabilecek; uygulama kullanmadığı hiçbir izni istemeyecek.**

## Tasarım

### `app/hesabim.tsx`

```
Hesabım
├── kullanıcı adı · e-posta · rol (Türkçe: Öğrenci / Öğretmen / Yönetici)
├── Şifreyi değiştir          → form (mevcut + yeni + tekrar) → başarıda: "Bütün cihazlarda oturumun kapandı" → giriş ekranı
├── Verilerimi indir          → JSON → paylaş sayfası → geçici dosya silinir
├── Hangi verilerim tutuluyor → GET /api/verim/envanter tablosu
├── Gizlilik politikası       → tarayıcı içi sayfa
├── Kullanım koşulları        → tarayıcı içi sayfa
└── Hesabımı sil              → iki adımlı onay + şifre
```

### Hesap silme akışı

1. Uyarı sayfası: **neyin silineceği** tablo hâlinde (envanterden) + "geri alınamaz".
2. "Devam" → şifre alanı + kırmızı "Hesabımı kalıcı olarak sil".
3. Yanıtlar:
   - `401` → "Şifre hatalı."
   - `400` + `gruplar` → "N grubun yöneticisisin" + grup adları + "Önce grupları devret"
   - `429` → "Çok fazla deneme, biraz bekle."
   - `200` → **yerel temizlik** → giriş ekranında "Hesabın silindi."
4. **Yerel temizlik kancası** — `lib/yerelTemizlik.ts` (tek yer):
   SecureStore jetonu · `@linguza_sentences_*` · `linguza_okuyucu_ayarlari` ·
   `linguza_kutlama_*` · `linguza_hatirlatma` · planlanmış bildirimler (YH-07) ·
   çevrimdışı önbellek (YH-13). **Çıkışta da** kişisel olanlar temizlenir.

### Verilerimi indir

```bash
npx expo install expo-sharing   # yeni paket — sürüm sabitlenir
```

`FileSystem.cacheDirectory/linguza-verilerim-<tarih>.json` → `Sharing.shareAsync` →
`finally` içinde dosya **silinir** (web'deki "sunucuda kopya kalmaz" ilkesinin cihazdaki karşılığı).

### Gizlilik / koşullar

`EXPO_PUBLIC_GIZLILIK_URL`, `EXPO_PUBLIC_KOSULLAR_URL` — **sır değil**, pakete
gömülmesi doğru. `expo-web-browser` (kurulu) ile açılır. Tanımsızsa bağlantı
"Hazırlanıyor" gösterir; YH-14'teki üretim yapılandırma denetimi **üretim
derlemesinde** tanımsızlığa izin vermez.

Kayıt ekranı: "Kaydolarak Kullanım Koşulları'nı ve Gizlilik Politikası'nı kabul etmiş olursun."

### Şifremi unuttum

Giriş ekranında bağlantı → e-posta formu → `POST /api/auth/forgot-password` →
**her durumda aynı metin** ("Eğer bu e-posta kayıtlıysa…" — enumerasyon yok).
`503` → "Şifre sıfırlama şu an kullanılamıyor." Bağlantı web'e gider (mobil
derin bağlantı kapsam dışı).

### OCR kamera butonları (insan kararı #7 — varsayılan: kaldır)

- "Fotoğraf Çek" ve "Galeriden Seç" **kaldırılır**.
- `app.json` → `expo-image-picker` eklentisi ve izin metinleri **çıkarılır**; paket kaldırılır.
- Yerine bilgi kartı: "Fotoğraftaki metni telefonunun **Canlı Metin** özelliğiyle kopyala, burada **Panodan Yapıştır**."
- Karar B (gerçek OCR) seçilirse: YH-14 sonrası ML Kit / Apple Vision; ayrı iş dosyası.

## Bitti kriteri

```bash
grep -rn "hesabimiSil\|verimiDisaAktar\|veriEnvanteri" mobile/src/lib/api.ts   # 3 sarmalayıcı
grep -c "expo-image-picker" mobile/app.json mobile/package.json               # karar A ise 0
bash scripts/guard/19-kisisel-veri.sh                                          # mobil bağlantı dâhil 0
cd mobile && npx tsc --noEmit
bash scripts/guard/run-all.sh
```

**Canlı deneme (yerel geliştirme veritabanı, önce yedek):** tek kullanımlık bir
hesap aç → kelime ekle → verilerimi indir (dosyada kelime var, `$2a$` yok) →
yanlış şifreyle silme (401) → doğru şifreyle silme → cihaz depolarının boş
olduğunu geliştirme günlüğüyle göster.

Görsel: hesabım · envanter · silme uyarısı · silme şifre adımı · grup sahibi hatası ·
şifremi unuttum · OCR bilgi kartı · kayıt ekranı onay metni.

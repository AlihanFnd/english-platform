## Tasarım dili — "tatlı, sade, oyun gibi"

İlham: oyunlaştırılmış dil uygulamalarının **"basılabilir taş"** hissi — alt
kenarı biraz kalın, yumuşak köşeli, açık renkli kutucuk. Ama okuma ekranı
olduğu için **sakin**: doygun renk yok, gölge yok, metin her zaman okunaklı.

### Kelime kutucuğu

```
 ╭────────╮ ╭─────╮ ╭──────────╮
 │  Tom   │ │ has │ │adventures│.     ← noktalama kutucuğun DIŞINDA
 ╰━━━━━━━━╯ ╰━━━━━╯ ╰━━━━━━━━━━╯
   isim      fiil       isim           ← alt kenar türün rengi
```

| Özellik | Değer | Neden |
|---|---|---|
| Köşe | `10` | Yumuşak, "taş" hissi |
| İç boşluk | yatay `6` · dikey `2` | Satır yüksekliğini patlatmadan dokunma alanı |
| Kutucuklar arası | yatay `4` · dikey `6` | Ayrışma — asıl sorun buydu |
| Zemin | tür rengi · açık temada `%12`, koyuda `%18` saydam | Sade; metin kontrastı korunur |
| Alt kenar | `2.5` px · tür rengi `%70` | "Basılabilir" his; Android'de de çalışır (kenarlık, dekorasyon değil) |
| Metin | `onSurface` — **tür rengiyle boyanmaz** | Okunabilirlik önce |
| Basınca | ölçek `0.94` + zemin `%26` + `Haptics.selectionAsync` | Oyun hissi, tatlı geri bildirim |
| Seçili (kelime kartı açık) | zemin `%30` + dört kenar ince tür rengi | Nerede olduğunu kaybetmez |
| Kelimelerimde kayıtlı | sağ üstte 6 px `primary` nokta | LingQ tarzı "bunu biliyorum/çalışıyorum" işareti, dikkat dağıtmadan |

### Tür renkleri (web'deki `.word-*` ile aynı aile)

| Tür | Renk | | Tür | Renk |
|---|---|---|---|---|
| isim | `#3B82F6` mavi | | edat | `#EC4899` pembe |
| fiil | `#10B981` yeşil | | bağlaç | `#F97316` turuncu |
| sıfat | `#F59E0B` amber | | zamir | `#06B6D4` camgöbeği |
| zarf | `#8B5CF6` mor | | diğer | `#94A3B8` gri |

### Sade mod

Kullanıcı ayarlardan **"Renkli kelimeler"i kapatabilir**: kutucuklar kalır
(ayrışma korunur), zemin nötr `surfaceContainer`, alt kenar `outlineVariant`.

### Noktalama

`kelimeyiAyir("adventures.")` → `{ on: '', govde: 'adventures', son: '.' }`.
Kutucuk **gövdeyi** gösterir; ön/son ek kutucuğun hemen yanında düz metin.
Böylece dokunulan kelime temizdir (YH-11'in ilk adımı: "conversation." sorunu
kaynağında kesilir). Yalnızca noktalamadan oluşan belirteç kutucuk olmaz.

### Başlıklar

`isHeading` cümleler kutucuğa **bölünmez** — başlık yazı tipinde, ortalı düz metin.

### Cümle eylemleri

Gizli hareket yerine görünür iki küçük düğme, cümlenin sağında dikey:

- 🔊 **Dinle** — `seslendir(cumle.original)`
- **TR** — Türkçesini aç/kapat (açıkken dolu)

Çeviri paneli cümlenin altında `FadeInDown` ile açılır; `ceviriBasarili === false`
ise uyarı rengi (KURAL-06 davranışı korunur).

Uzun basma → **kalıp seçimi** (mevcut davranış) korunur.

## Sayfa geçişleri

### Kural: ekran hiçbir geçişte boşalmaz

- İlk açılış: tam ekran yükleyici **yalnızca bir kez**.
- Sayfa değişimi: başlık, üst ilerleme çizgisi ve alt çubuk **yerinde kalır**;
  içerik alanında **iskelet kutucuklar** (yavaş nabız) görünür.

### Yön bazlı geçiş

| Geçiş | Çıkan içerik | Giren içerik |
|---|---|---|
| İleri (sonraki sayfa) | `FadeOutLeft` · 160 ms | `FadeInRight` · 280 ms · `Easing.out(cubic)` |
| Geri | `FadeOutRight` · 160 ms | `FadeInLeft` · 280 ms |
| İlk açılış / atlama | — | `FadeIn` · 220 ms |

İçerik `Animated.View key={sayfaAnahtari}` içinde; anahtar değişince
Reanimated giriş/çıkış animasyonunu kendisi yürütür.

> **Neden kaydırma (slide) değil solma+kayma:** tam genişlikte kayma okuma
> sırasında "başka ekrana geçtim" hissi veriyor ve 300 kutucukta kare
> düşürebiliyor. Kısa mesafeli solma+kayma yumuşak ve ucuz.

### Parmakla sayfa çevirme

`GestureDetector` + `Gesture.Pan()`:

```ts
Gesture.Pan()
  .runOnJS(true)
  .activeOffsetX([-30, 30])   // yatay niyet netleşmeden devreye girmez
  .failOffsetY([-18, 18])     // dikey kaydırma önceliklidir
  .onEnd((e) => {
    if (e.translationX < -80 || e.velocityX < -650) sonraki();
    else if (e.translationX > 80 || e.velocityX > 650) onceki();
  });
```

Sınırda (ilk/son sayfa) hafif `Haptics.notificationAsync(Warning)`.

### Üst ilerleme çizgisi

Başlığın altında 3 px, `withTiming(yuzde, 360 ms)` ile dolan çizgi.

### Hareket azaltma

`useReducedMotion()` true ise: giriş/çıkış animasyonları **verilmez**, ölçek
efekti kapanır, iskelet nabzı durur. (Erişilebilirlik — iOS "Hareketi Azalt".)

| Ayar | Değerler | Varsayılan |
|---|---|---|

| Renkli kelimeler | açık / kapalı | açık |
| Renk rehberi | tür → renk listesi (salt bilgi) | — |

`Önceki · sayfa göstergesi · Sonraki` kalır.

## Tuzaklar

| Tuzak | Neden olur | Nasıl kaçınılır |
|---|---|---|
| **İç içe `Text` ile kutucuk denemek** | RN iç içe `Text`'e padding/radius/border uygulamaz | Her kelime `View`; satır `flexDirection: row, flexWrap: wrap` |
| **Boşluğu kutucuğun içine koymak** | Eski hatanın aynısı | Aralık `gap`/`margin` ile |
| **Uzun kelime taşması** | Dar ekranda tek kelime satırdan geniş | `maxWidth: '100%'` + `flexShrink: 1` |
| **Sayfa değişiminde çift istek** | `konum` ve `yukle` bağımlılığı iki kez tetiklenirse `analyze-page` iki kez çağrılır (💰) | Tek istek bayrağı + istek sırası (`KelimePaneli`'ndeki `istekSirasi` deseni) |
| **Eski yanıtın yeni sayfayı ezmesi** | Hızlı ileri-ileri basışta 3. sayfanın yanıtı 4.'den sonra gelir | İstek sırası karşılaştırması |
| **Kaydırma ile yatay jest çakışması** | Dikey okurken sayfa değişir | `failOffsetY` + eşik |
| **`exiting` animasyonu + yükleniyor** | İçerik çıkarken yeni içerik yoksa boş kare görünür | Çıkış kısa (160 ms), iskelet hemen girer |
| **Hareket azaltmayı unutmak** | Vestibüler rahatsızlığı olan kullanıcı | `useReducedMotion` |
| **Renkli kelimeyi metin rengine uygulamak** | Sarı üstünde beyaz metin okunmaz | Renk yalnızca zemin ve kenarda |
| **`memo` karşılaştırmasında dizi kimliği** | Her render'da yeni dizi → memo boşa | Seçim imzası **dize** olarak geçer |

## 1. EAS ve development build

```json
// mobile/eas.json
{
  "cli": { "version": ">= 16.0.0", "appVersionSource": "remote" },
  "build": {
    "development": { "developmentClient": true, "distribution": "internal", "channel": "development" },
    "preview":     { "distribution": "internal", "channel": "preview" },
    "production":  { "autoIncrement": true, "channel": "production" }
  },
  "submit": { "production": {} }
}
```

- `npx expo install expo-dev-client expo-updates` → `app.json`: `runtimeVersion: { policy: "appVersion" }`, `updates.url`.
- Development build'den sonra Expo Go **birincil ortam olmaktan çıkar**; native modül isteyen işler (gerçek OCR, Sentry) açılır.

## 2. Üretim yapılandırma sözleşmesi (mobil) — `lib/yapilandirma.ts`

Sunucudaki `OrtamSozlesmesi`'nin istemci karşılığı:

| Değişken | Geliştirme | Üretim derlemesi (`!__DEV__`) |
|---|---|---|
| `EXPO_PUBLIC_API_URL` | yoksa Expo sunucusunun LAN IP'si | **zorunlu** ve `https://` ile başlamalı |
| `EXPO_PUBLIC_GIZLILIK_URL` | isteğe bağlı | **zorunlu**, `https://` |
| `EXPO_PUBLIC_KOSULLAR_URL` | isteğe bağlı | **zorunlu**, `https://` |
| `EXPO_PUBLIC_SENTRY_DSN` | isteğe bağlı | isteğe bağlı (yoksa raporlama kapalı) |

Üretimde zorunlu biri eksik/geçersizse uygulama **"Yapılandırma hatası"
ekranında durur** — `localhost`'a düşmez (CLAUDE.md: "yapılandırma eksikken zayıf
bir yedeğe düşmek yasaktır"). Ayrıca `eas build` öncesi `scripts/mobil/uretim-yapilandirma.mjs`
aynı denetimi yapıp derlemeyi durdurur.

## 3. Çökme raporlama (insan kararı #9)

Karar **evet** ise `@sentry/react-native` (development build ister):

- `beforeSend`: e-posta, `Authorization` başlığı, URL sorgu parametreleri, **kelime/cümle/OCR metni** silinir.
- Kullanıcı kimliği yalnızca sayısal `id` (e-posta yok).
- Oturum tekrarı (session replay) **kapalı**.
- DSN yoksa özellik kapanır, uygulama çalışır (dış servis sınıfı: *işlev bozulur, güvenlik etkisi yok*).
- Gizlilik politikasına ve mağaza gizlilik etiketine eklenir.

## 4. Sürüm sabitleme

`package-lock.json`'daki çözülmüş sürümlerle `^`/`~` kaldırılır.
`scripts/guard/18-tedarik.sh` "package.json sürüm aralığı" maddesi `mobile/package.json`'ı da kapsar.

> `expo` SDK paketleri `npx expo install --check` ile uyum denetlenir; sabitleme uyumu bozmaz.

## 5. Mobil CI işi

```yaml
mobil:
  runs-on: ubuntu-latest
  defaults: { run: { working-directory: mobile } }
  steps:
    - uses: actions/checkout@v4
    - uses: actions/setup-node@v4
      with: { node-version: 22, cache: npm, cache-dependency-path: mobile/package-lock.json }
    - run: npm ci
    - run: npx tsc --noEmit
    - run: npx expo lint
    - run: npx expo install --check
    - run: npm audit --audit-level=high      # istisnalar: guvenlik/zafiyet-istisnalari.json
    - run: npx jest --ci
    - run: node ../scripts/mobil/erisilebilirlik-denetimi.mjs
    - run: node ../scripts/mobil/tip-sozlesmesi.mjs
```

`scripts/ci-yerel.sh` aynı adımları yerelde koşturur.

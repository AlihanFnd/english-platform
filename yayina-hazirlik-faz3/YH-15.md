## Hedef

> **Web öğrenci istemcisi seriyi, günlük hedefi, cümle kurmayı ve kelime
> kutucuklarını mobil ile aynı sözleşmeyle sunacak; raporlar ve belgeler
> ölçülerek yenilenecek; faz 3 ilerleme tablosunun tamamı kanıtla kapanacak.**

---

## A. Web eşitliği

| Özellik | Web'de | Not |
|---|---|---|
| Seri kartı (panel) + üst çubukta alev | `app/page.tsx`, `layout-wrapper.tsx` | `GET /api/seri` |
| `/seri` sayfası + hedef seçimi | `app/seri/page.tsx` | `PUT /api/seri/ayarlar`; saat dilimi `Intl` |
| Kelime kutucukları | `app/books/[id]/page.tsx` | Tailwind; mevcut `.word-*` renkleri kutucuk zeminine |
| Cümle kurma modu | aynı sayfa | tıklama ile sıralı seçim + alt panel |
| Cümlelerim API'ye | `app/words/page.tsx` | YH-05 göçü (localStorage → sunucu) |
| Sayfa geçişi | aynı sayfa | CSS `@keyframes` (JS animasyon kütüphanesi eklenmez) + `prefers-reduced-motion` |

### Web'e özel güvenlik

- **CSP nonce zinciri korunur** — `layout.tsx`'teki `await headers()` satırına dokunulmaz; guard 11 yeşil.
- Yeni üçüncü taraf JS **yok** (CDN yasağı); animasyonlar CSS.
- `style-src 'unsafe-inline'` genişletilmez.
- HTTP çağrıları yalnızca `frontend/app/api.ts`.

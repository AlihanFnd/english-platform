# YH-13 — Çevrimdışı okuma ve yazma kuyruğu

> **Bağımlılık:** YH-05 (cümle ucu kuyruğa girer).

---

## Hedef

> **Kullanıcı internet yokken son okuduğu kitapların hazır sayfalarını
> okuyabilecek, kelime ve cümle kaydedebilecek, kart çalışabilecek; bu yazmalar
> bağlantı gelince sırayla ve bir kez sunucuya gidecek; çevrimdışı indirme hiçbir
> zaman ücretli analizi tetiklemeyecek.**

---

## Mevcut durum

Her ekran her açılışta ağ istiyor; önbellek yok, ağ durumu bilinmiyor
(`package.json`'da `netinfo` yok). Metroda/uçakta uygulama boş.

---

## Kapsam (v1)

| Dahil | Hariç |
|---|---|
| Son okunan 3 kitapta, son konumun ±5 **analizi hazır** sayfası otomatik | Analizsiz sayfayı çevrimdışı analiz |
| Kitap sayfasında "Çevrimdışı indir" (yalnızca **analizi hazır** sayfalar) | Bölüm modundaki kitaplar (her okumada analiz üretiyor) |
| Yazma kuyruğu: ilerleme · kelime ekleme · çalışma sonucu · cümle ekleme | Grup işlemleri, hesap işlemleri |
| Çevrimdışı bandı | Çevrimdışı quiz üretimi |

## Backend — salt okunur toplu sayfa ucu

`GET /api/books/{id}/sayfalar?bas=1&son=50`

| | |
|---|---|
| Yetki | `[Authorize]` (kitaplar global) |
| Kota | `Okuma` |
| Sınır | `son - bas + 1 <= 50` → değilse 400 |
| **Yazar mı?** | **Hayır** — ilerleme yazmaz, analiz üretmez (KURAL-17) |
| Yanıt | `[{ pageNumber, content, sentencesJson, analizBekliyor }]` — analizsiz sayfa `sentencesJson: null` |

Testler: `Toplu_sayfa_ucu_ANALIZ_URETMEZ` (Groq çağrı sayacı 0) · `Toplu_sayfa_ucu_YAZMAZ` ·
`Toplu_sayfa_SINIRI` (51 → 400) · `Olmayan_kitap_404`.

## İstemci

### Ağ durumu

```bash
npx expo install @react-native-community/netinfo   # sürüm sabitlenir
```

`context/AgContext.tsx` → `cevrimiciMi`. Üstte ince bant: "Çevrimdışısın — kayıtların bağlantı gelince gönderilecek (3)".

### Önbellek — `lib/cevrimdisiDepo.ts`

- `FileSystem.documentDirectory + 'cevrimdisi/<kitapId>/<sayfa>.json'`
- İndeks dosyası: son erişim zamanı, boyut. **Tavan 50 MB**, LRU ile silinir.
- Okuyucu: çevrimiçi → ağ; ağ hatası ya da çevrimdışı → önbellek; ikisi de yoksa "Bu sayfa çevrimdışı hazır değil".

### Yazma kuyruğu — `lib/yazmaKuyrugu.ts` (SAF çekirdek + depolama)

```
{ id (uuid), tur, govde, olusturma, deneme }
```

| Kural | Neden |
|---|---|
| **Birleştirme:** aynı kitabın `ilerleme` işlerinden yalnızca sonuncusu kalır | 40 sayfa ileri-geri = 1 istek |
| Sıra korunur (FIFO) | Kelime eklenmeden çalışma sonucu gitmesin |
| Uçlar zaten **idempotent** (addword, cümle) | Çift gönderim çift kayıt üretmez |
| 401 → kuyruk **durur**, silinmez; girişten sonra devam | Oturum düşünce veri kaybolmasın |
| 4xx (401/429 hariç) → iş düşürülür + günlüğe | Geçersiz iş kuyruğu sonsuza kilitlemesin |
| 429 / ağ → üstel geri çekilme | Hız sınırını dövmesin |
| Tavan 500 iş | Sınırsız büyüme yok |

> **Seri notu:** kuyruktan geç giden ilerleme puanı **gönderildiği günün** XP'si
> olur (sunucu günü hesaplar). Çevrimdışı gün seriyi uzatmaz — bilinçli: istemci
> tarihine güvenilmez (YH-04 karar 4). Kullanıcıya bantta bir kez açıklanır.

## Güvenlik ve gizlilik

| Soru | Cevap |
|---|---|
| Önbellekte kişisel veri? | Sayfa içeriği paylaşılan kitap içeriği (kişisel değil). **Kuyruk kişiseldir** (kelime, cümle) |
| Çıkış / hesap silme | Kuyruk ve önbellek YH-08 temizlik kancasıyla silinir |
| Başka kullanıcı aynı cihazda | Kuyruk `userId` ile anahtarlanır; başkasının kuyruğu gönderilmez |
| Maliyet | Toplu uç analiz üretmez; indirme analizsiz sayfayı atlar |

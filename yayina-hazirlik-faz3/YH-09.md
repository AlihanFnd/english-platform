## Erişilebilirlik kuralları

| Kural | Uygulama |
|---|---|
| Yalnızca ikondan oluşan her dokunulabilir öğe | `accessibilityLabel` + `accessibilityRole="button"` |
| Durum taşıyan öğe | `accessibilityState={{ selected, disabled, checked }}` |
| Dokunma alanı | görsel boyut < 44 pt ise `hitSlop` |
| Dinamik yazı boyutu | okuma metni **ölçeklenir**; sekme etiketleri `maxFontSizeMultiplier={1.3}` |
| Renk tek bilgi taşıyıcısı değil | tür rengi + erişilebilirlik etiketinde tür adı |
| Kontrast | metin her zaman `onSurface`; renkli zeminler %12–18 |
| Hareket | `useReducedMotion` |

### Denetim betiği — `scripts/mobil/erisilebilirlik-denetimi.mjs`

`Pressable` / `TouchableOpacity` bloklarını tarar; içinde **metin çocuğu olmayan**
ve `accessibilityLabel` taşımayan blokları dosya:satır olarak listeler.

> Güvenlik kapısı değil (`run-all.sh`'e girmez) — **mobil kalite kapısı**;
> YH-14'te mobil CI işine eklenir.

## Bitti kriteri

```bash
grep -rn "textTransform: 'uppercase'\|textTransform: 'capitalize'" mobile/src   # BEKLENEN: 0
node scripts/mobil/erisilebilirlik-denetimi.mjs                                 # BEKLENEN: 0 adsız düğme
cd mobile && npx tsc --noEmit
bash scripts/guard/run-all.sh
dotnet test Linguza.sln   # dashboard projeksiyon değişikliği
```

Görsel: bütün sekmelerin açık/koyu ekran görüntüsü seti (`mobile/screenshots/faz3/YH-09-*`) ·
VoiceOver açıkken okuyucu (Erişilebilirlik Denetçisi) · büyük yazı boyutunda panel.

## Tuzaklar

| Tuzak | Nasıl kaçınılır |
|---|---|
| `toLocaleUpperCase` iç içe `Text` çocuklarında | Yalnızca dize çocuk; karışık çocukta biçimlendirme çağıran tarafta |
| Etiketi her yere aynı yazmak ("düğme") | Eylemi söyleyen etiket: "Kelimeyi sil: conversation" |
| Dinamik yazıyı her yerde kapatmak | Yalnızca yoğun yerleşimlerde çarpan sınırı |

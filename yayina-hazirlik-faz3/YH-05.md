# YH-05 — Cümlelerim sunucuya taşınır

> **Bağımlılık:** YH-03 (okuyucudan cümle kaydı), YH-04 (seri puanı).

---

## Hedef

> **Kullanıcının kaydettiği cümleler hesabına bağlı olarak sunucuda duracak;
> web ve mobil aynı listeyi görecek; cümleler kişisel veri envanterinde,
> dışa aktarmada ve hesap silmede yer alacak; cihazdaki eski kayıtlar
> kayıpsız sunucuya taşınacak.**

## Veri modeli

```csharp
public class CumleKaydi
{
    [Key] public int Id { get; set; }
    public int UserId { get; set; }
    [ForeignKey("UserId")] public User User { get; set; } = null!;

    [Required, MaxLength(AlanSinirlari.Cumle)]          public string Cumle { get; set; } = "";
    /// <summary>Tekillik anahtarı: küçük harf + boşluk sadeleştirilmiş. Kullanıcı görmez.</summary>
    [Required, MaxLength(AlanSinirlari.Cumle)]          public string CumleAnahtari { get; set; } = "";
    [MaxLength(AlanSinirlari.CumleCevirisi)]            public string Ceviri { get; set; } = "";
    [MaxLength(AlanSinirlari.CumleBaglami)]             public string Baglam { get; set; } = "";
    public DateTime AddedAt { get; set; }

    public int DogruSayisi { get; set; }
    public int YanlisSayisi { get; set; }
    public int DogruSeri { get; set; }
    public DateTime? SonCalismaAt { get; set; }
}
```

## API — `Controllers/CumlelerController.cs` · `api/cumleler`

| Uç | Kota | Not |
|---|---|---|
| `GET /` | — | kendi listesi, yeniden eskiye, **projeksiyon** (entity dönmez) |
| `POST /` | `Yazma` | idempotent; **gerçekten yeni** ise `CumleXp` +3 (YH-04) |
| `PUT /{id}` | `Yazma` | sahiplik sorguda; `CumleAnahtari` yeniden hesaplanır; çakışma → 409 "Bu cümle listende zaten var." |
| `DELETE /{id}` | `Yazma` | sahiplik sorguda; idempotent; yok/başkasının → aynı yanıt |
| `POST /toplu` | `Yazma` | en çok 200 öğe; **puan VERMEZ** (içe aktararak seri doldurulmaz); eklenen/atlanan sayısı döner |
| `GET /calisma?adet=` | — | `KelimeCalismasi` ile aynı sıralama (YH-06 sonrası tekrar zamanı) |
| `POST /calisma-sonucu` | `Yazma` | sayaçlar **sunucuda**; sahiplik; `CalismaXp` +1 |
| `GET /ozet` | — | toplam / öğrenildi / çalışılıyor / hiç |

Kural: `/api/cumleler/{id}` altında **başka kullanıcıyı** gösteren tek bir dal
olmamalı — her sorgu `Where(c => c.UserId == userId)` ile başlar.

## Cihazdan sunucuya göç

`lib/cumleGocu.ts` (mobil) ve `app/lib/cumleGocu.ts` (web):

```
girişten sonra, bir kez:
  yerel = cihaz deposundaki cümleler
  yerel boşsa → bayrak yaz, çık
  200'lük parçalar hâlinde POST /api/cumleler/toplu
  HER parça başarılıysa → yerel anahtarı SİL → bayrak yaz (linguza_cumle_gocu_<userId>)
  bir parça başarısızsa → HİÇBİR ŞEY silinmez, bir sonraki açılışta yeniden denenir
```

- Tekillik sayesinde yarım kalıp tekrar denenen göç **çift kayıt üretmez**.
- Göç istatistikleri (`dogruSeri` vb.) **taşımaz** — istemciden gelen sayaç güvenilmez;
  kullanıcıya bir kez "Cümlelerin hesabına taşındı (N cümle)" bildirimi.
- `cumleKaydet()` (YH-03) artık `api.cumleEkle` çağırır; `words.tsx` Cümlelerim sekmesi API'ye geçer.

## Tuzaklar

| Tuzak | Nasıl kaçınılır |
|---|---|
| Göçte önce silip sonra göndermek → veri kaybı | Silme yalnızca **tüm** parçalar başarılıysa |
| Tekilliği `Cumle` üzerine kurmak | Büyük/küçük harf farkı çift kayıt üretir → `CumleAnahtari` |
| B-tree dizin boyutu | 500 karakter UTF-8 ≤ 2000 bayt, PostgreSQL sınırının (≈2700) altında |
| İstemci sayaçlarını göçte taşımak | Güvenilmez veri — taşınmaz |
| Web ve mobilin aynı anda göç etmesi | Tekillik + idempotent toplu uç |
